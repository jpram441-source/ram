# GHSS Silattur - School Management System

Live URL: https://jpram441-source.github.io/ram/

## Features
- Owner Login: Can create Owner, Teacher, Student (Owner ID creation only by Owner)
- Teacher Login: Can create Student only, Add Assignment, Add Quiz
- Student Login: Login with EMIS Number, View Assignments, Attend Weekly Quiz (Subject wise one time per week)
- Forgot Password with eye button for password visibility
- Database: localStorage (Works on GitHub Pages without backend)
- Login page has no owner info display

## Default Login
- Username: owner
- Password: owner123
- Role: Owner

## How to Publish on GitHub
1. Create repository named `ra`
2. Upload all files (index.html, forgot.html, css/style.css, js/db.js, README.md)
3. Go to Settings > Pages > Branch: main / root > Save
4. Wait 2 minutes, site will be live at https://jpram441-source.github.io/ra/

## Technologies
- HTML, CSS, JavaScript
- localStorage as Database
